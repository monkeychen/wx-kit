# wx-kit v0.8.7 产品需求文档（未发布、已取消）

> **状态：取消，从未发布；被 v0.9.0 取代**（2026-08-08）。
>
> 本文件只记录原收集需求的最终去向。当前产品范围与验收统一见 `docs/PRD-v0.9.0.md`。

## 1. 取消原因

v0.8.7 原本建立在公众号订阅、私有文章列表和后台登录仍可继续使用的前提上。该前提已经失效，
继续按原 PRD 实施只会维护不可达页面。另一方面，产品主线收缩属于明显边界变化，也不适合继续使用
v0.8.x 的普通迭代编号，因此 v0.8.7 不发布，下一公开版本直接为 v0.9.0。

## 2. 原需求去向

| 原需求 | 最终处理 | 归属 |
|---|---|---|
| R1 订阅页两个链接缺手型 | 取消；问题所在页面已退场，当前有效界面没有同类已知缺陷 | 无 |
| R2 GitHub 安全告警 | 保留，但必须重新获取实时告警，不能沿用旧快照 | v0.9.0 M50 |
| R3 README 重做 | 已随 M49 重写；当前有效页面截图与发布信息继续完善 | v0.9.0 M49/M51 |
| R4 订阅 pending 违规文章状态 | 取消；pending、订阅页和检查链路均已退场 | 无 |
| 原 R5 重新登录/彻底退出 | M47 底层清理已实现并保留，用户入口随 M49 退场 | v0.9.0 吸收的历史实现 |

## 3. 不再实施

- 不拆 v0.8.7 里程碑；
- 不为订阅页补交互细节或 pending 状态；
- 不恢复公众号后台登录、列表、抓取或订阅；
- 不发布 v0.8.7 tag、安装包、GitHub Release 或 brew cask。
