# M66 · 统一诊断日志 main.log(v0.11.3 候选 R)

> 背景(2026-09-19 安哥发起,brainstorm 定案):项目至今无统一日志模块——7 处零散
> console 调用在打包 GUI(Finder 启动 stdout 进黑洞)上用户/开发者都看不到,仅有
> `subscriptions-check.log`(人类可读检查记录)与 `mp-request-audit.log`(微信请求
> 治理审计)两个专用文件。v0.11.2 的 mocli BAD_OUTPUT 事故里,真正的线索
> (`env: node: No such file or directory`)在子进程 stderr 随进程消失,排障靠猜。
> 本里程碑给 app 落一个**默认常开 info 级**的结构化诊断日志,报障话术升级为
> 「设置 → 打开日志文件夹,把 main.log 发我」。

## 已定设计决策(勿再议)

- **JSON 行格式** `{time, level, domain, event, msg, ...fields}`:agent 排障友好,`msg` 人类可读。
- **自写轻量,不引 electron-log**:功能仅轮转+脱敏,~150 行。
- **落盘层放 `src/core/`(纯 node fs,零 electron import)**:埋点最深处在 core 边界
  (mocli runner),logger 若在 electron/services 会被 core 反向 import 违反分层。
  userData 路径由 GUI/CLI 入口各自传入 init。
- **模块级可选单例**(违反「无全局」洁癖,换埋点零侵入):`getLogger()` 未 init 返回
  null,埋点一行 `diag()?.info(...)`,不给业务函数加 logger 参数。
- **脱敏红线**:敏感 key(cookie/wr_skey/token/key/sign/auth_key/ticket/secret 等,
  大小写不敏感)值→`«redacted:N»`;URL query 敏感参数打码。**宁可漏记不可泄密**。
- **默认常开 info;5MB 轮转,保留 3 代(main/main.1/main.2,上限 ≈15MB)**。
- 三个专用日志文件(audit/check)保留不吞并;主日志只记 subs 检查一行摘要。
- 无 GUI 日志查看器、无远程上报(YAGNI/隐私)。

## Task 1 · core:diag-log 纯逻辑 + 落盘单例(TDD)

**`src/core/diag-log.ts`**(新文件,唯一 IO 依赖 node:fs/promises):

- `redact(value): unknown` — 深度遍历(对象/数组,防循环引用);命中敏感 key
  (清单:`cookie` `wr_skey` `wr_vid` `token` `key` `apikey` `api_key` `auth_key`
  `sign` `signature` `ticket` `secret` `password` `authorization`,不区分大小写)
  的字符串/任意值 → `«redacted:len»`;URL 字符串经 `redactUrl`(query 里同名参数
  值打码,其余 query 保留——下载排障需要看 count/format 等参数)。
- `formatLogLine(level, domain, event, fields, msg): string` —
  `JSON.stringify({time: new Date().toISOString(), level, domain, event, msg,
  ...redact(fields)})`,fields 非对象时不展开。
- `shouldLog(level, minLevel): boolean` — debug < info < warn < error。
- `initDiagLog(opts: { dir: string; minLevel?: Level; now?: () => number })` —
  建目录、初始化单例。**幂等**:重复 init 返回现有实例(GUI+CLI 不会双 init,防御)。
- `diag(): DiagLog | null` — 单例访问;未 init 返回 null。`DiagLog` 接口:
  `debug/info/warn/error(domain, event, fields?, msg?)`,内部 `appendFile(path,
  line + '\n')`,写失败 `console.warn` 一行(日志永不拖垮业务,try/catch 包死)。
- 轮转:写前 `stat`,超过 `maxBytes`(默认 5MB)→ `main.2` 删、`main.1`→`main.2`、
  `main`→`main.1`(rename 链,fs 注入——`opts.fs` 可注入 `{stat, rename, unlink,
  mkdir, appendFile}` 供单测,默认真 fs/promises)。**非事务,尽力而为**:轮转失败
  就继续写(丢轮转不丢日志)。
- 串行化:并发 appendFile 用进程内 promise 链排队(行级交错是 O_APPEND 也可能
  出的,链化零成本保险)。

**测试**(`tests/core/diag-log.test.ts`,注入 fs mock + 真 tmpdir 各一半):
- redact:敏感 key 各形态命中(含嵌套/数组/大小写);非敏感值原样;URL query
  打码(`auth_key=abc` → `auth_key=«redacted:3»`,正常参数保留);循环引用不爆栈。
- formatLogLine:形态断言(time/level/domain/event/msg/fields 展开)。
- shouldLog:min=info 时 debug 拒、info/warn/error 过。
- initDiagLog 幂等:二次调用不重建(同一实例/同一 minLevel)。
- 写入:info 落一行合法 JSON;未 init 时 `diag()` 为 null 不抛。
- 轮转(mock fs):超限触发 rename 链(main.2 删除、逐级位移);rename 抛错不
  影响本次写入继续走 appendFile。
- 真 tmpdir 冒烟:写 3 行读回逐行 JSON.parse 通过。

## Task 2 · 埋点接入(4 处边界,每处 ≤5 行)

**a. `electron/main.ts` GUI 启动**(registerIpc 前):
`initDiagLog({ dir: join(app.getPath('userData'), 'logs') })` + 一条
`startup/snapshot`:app 版本(package.json version 经 app.getVersion())、
electron/node/chrome 版本、platform/arch、mode:'gui'、userData、libraryRoot(从
settings)、`PATH/HOME/SHELL`(事故级线索)、weread 凭据文件存在与否(只记布尔)。

**b. `src/cli/index.ts` CLI 入口**(program parse 前或 dispatch 后):
同 init(路径取 electron app.getPath('userData') 的等价物——CLI 模式下 main.ts
`app.isPackaged` 分支已可用 `app.getPath`,在 runCli 收到 userData 参数?——
**勘察点**:CLI 模式 userData 获取方式,若 runCli 无 electron app 引用,则 CLI 的
diag 落 `~/.wx-kit/logs/` 或跳过(实现时按勘察结果定,倾向:main.ts 的 CLI 分支
在 runCli 之前 init,GUI/CLI 统一 userData/logs)。snapshot 带 mode:'cli' +
argv 摘要(子命令与 flag key,不记 URL 全文——URL 记在具体事件里)。

**c. `electron/services/mowen-detect.ts`**:`runStartupMowenDetect` 成功/失败两分支
各记一条 `startup/mocli-located`:path/version/detectedAt;失败记 error 分支
(msg)。探测链逐步结论第一版不记(detectMocli 返回值里没有,改它签名不值)。

**d. `src/core/mowen/runner.ts` `createMocliRunner`**(唯一 mocli 执行通道,一处
全覆盖):spawn 前 `info('mocli','spawn',{bin,args})`;回调里
`info('mocli','exit',{code,ms,stdout1,stderr1})`——stdout/stderr 取首行截
120 字符。ENOENT reject 路径记 `warn('mocli','not-found',{bin})`。

**e. `electron/ipc.ts` download 边界**:`download:url` handler 结果处记
`download/done|fail`:`{url, ok, skipped, formats, ms}`(失败带 error message;
canonicallId 有则记)。**勘测点**:handler 现有返回结构,顺字段即可。

**f. weread 请求网关**(`electron/services/mp-request-gateway.ts` 的
requestWereadJson 统一出口):`weread/request {endpoint, bizCode, ms, attempt}`,
失败记 warn。**克制**:不打请求体/响应体,只记码与耗时。

各埋点统一形态 `diag()?.info(domain, event, fields, msg)`——null 安全,测试环境
不 init 即零开销。

**测试**:现有全量回归不破(埋点不 init 不生效);`tests/electron/` 增一个
「init 后 mocli exit 事件落盘」的真 tmpdir 用例(用 createMocliRunner 跑
`node -e ""` 之类的真实子进程,断言 main.log 有合法 JSON 行)。
