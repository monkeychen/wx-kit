# M70 · 选题 GUI 与安全 Key 保存实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task and superpowers:test-driven-development for behavior. 完成后按 AGENTS 自动合 main，不 push。

**Goal:** 将已确认的 B 方案接入真实 Electron 应用，提供安全的 BYOK 配置、选题分析、详情、反馈和简报闭环。

**Architecture:** 主进程服务持有模型配置和分析 AbortController；renderer 只经 preload IPC 使用共享 M68/M69 核心。公开 base URL/model 放 settings，Key 用 Electron safeStorage 加密文件；加密不可用时只保留当前服务实例内存并明确显示“重启后需重填”。

**Tech Stack:** Electron safeStorage/ipcMain/preload、React 18、Ant Design 6、现有 CSS、Vitest、Playwright Electron e2e；无新依赖。

**Spec:** [本地选题决策器设计](../superpowers/specs/2026-09-20-topic-decisions-design.md)

## Global Constraints

- 页面沿用已确认 B 方案：三个候选平等展示、默认不选中；点选后同页展开“为什么值得写 / 材料依据 / 怎么下笔”。
- 初始默认 24 小时；可选择 3 天、7 天和自定义日期；不自动扩窗。
- 未配置模型时引导到设置；正文发送外部服务的事实在设置与分析页可见。
- renderer 永远读不到 Key；普通 settings JSON、IPC 返回、stdout、result、trace、日志均不得包含 Key。
- safeStorage 不可用时只做会话内保存，界面必须说明重启需重填；不能回退明文文件。
- 同一时刻只允许一个 GUI 分析；支持取消。切换卡片/页签、反馈和生成简报不发模型请求。
- 反馈按事件独立落盘，不把“暂不写”扩大成永久主题偏好；不做后台监控。
- 外链只通过现有 `shell:openExternal` 的 https 白名单；本地简报可复制并在 Finder 中显示。
- GUI fixture e2e 使用本地 HTTP 模型，不读真实 Key、不访问外部服务；真实语义质量仍未验证。
