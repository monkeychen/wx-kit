# v0.10.0 发布说明

**订阅回来了，批量下载留在那里。**

v0.9.0 因 MP 后台私有接口被封而退场的能力，这一版通过**微信读书（WeRead）Web 端**
重建了订阅闭环；但实施中撞上服务端按账号封禁列表接口（三轮 spike 证伪一切客户端手段），
按号批量下载再次停用——能力边界如实收缩，不再给半成品入口。

### 能力复活

*   **公众号订阅闭环**：粘贴该号任意一篇文章链接即可识别并订阅（微信读书无按名搜索），
    定期检查、发现新文章自动下载、水位增量——日常订阅体验回到 v0.8.5 形态。
*   **微信读书扫码登录**：应用内与 CLI 终端直接渲染二维码（Web 端
    `weread.qq.com/api/auth` 协议，走内嵌 Chromium 网络栈），凭据本地 0600 落盘，
    `session export/import` 支持跨机迁移。
*   **CLI 订阅命令组**：`search --url` / `login` / `auth-status` / `subscription
    list/check-now/digest` / `session` / `protection` 全部可用。

### 订阅页体验修正（用户实测反馈）

*   **新旧标识自动归一**：旧版订阅的 base64 形态账号与新版 `MP_WXS_` 形态自动合并，
    不再出现同名重复行；水位、待处理文章无损合并。
*   **订阅可删除**：每行新增删除入口（二次确认），删除标记持久化，历史派生行不会复活；
    重新订阅自动撤销标记。
*   **行内检查隔离**：点单行「检查」只查该号且只有本行进入检查态，
    不再牵动整页与「检查全部」。

### 能力边界（必须言明）

*   **[停用] 按公众号批量下载**：微信读书列表接口（`web/mp/articles`，移动端
    `/mp/chapters` 同源）被服务端**按账号**封禁——2026-08-27 用真 Chrome 全新扫码
    登录验证仍 `-2041`，与客户端无关、无工程解。GUI 入口已移除，CLI `crawl` 稳定拒绝
    `MP_BACKEND_UNAVAILABLE`（退出码 2，零网络请求）。恢复条件只能是官方放开。
*   **[降级] 仅最新一篇**：`/api/mp/cover` 每次只返回该号最新文章，订阅检查据此增量；
    `digest` 亦仅覆盖最新一篇，无法回补历史。
*   **[降级] 无按名搜索**：识别公众号统一改为粘贴该号任意文章链接。

### 底层变更

*   **微信读书适配层**（`src/core/weread/`）：后端再死，退场的只是一个适配器；
    订阅/抓取编排层语义不变。
*   **网络栈**：微信读书流量走内嵌 Chromium 会话（`weread-net.ts`，
    `persist:weread` 分区）；mp.weixin 文章页沿用既有 Chromium 链路。
*   **判重兜底**：无 `hint` 短链下载后自动从文章页提取 `mid/idx` 归一，
    订阅下载与手动下载互认不重复。
*   **登录链路教训固化**：数字 `vid`、`reviewId` token `~↔_` 与 mp 短链不一致的
    自动回退、登录全量 Cookie 落盘——全部沉淀进代码与测试。
