# v0.10.5 · 修复：登录态失效不再伪装成「没有新文章」

发布日期：2026-09-09 · 修复两项（源自实测反馈）

## 修复

### 检查报「没有新文章」，实际是登录态失效

微信读书登录态（`wr_skey`）过期后，订阅检查会把接口 401 吞成空结果——显示「没有新文章」，
实际一篇都没查过，且「需重新登录」的黄色提示不出现。现在：

- 登录态失效时，订阅检查如实报失效：订阅页顶部出现「订阅检查需重新登录微信读书」提示、
  检查记录落 `auth-expired`、CLI 输出 `note: 'auth-expired'` + `authExpired: true`。
- 排查实录：安哥发现腾讯云开发者、刘备教授当天有新文章但检查报无——直连 cover 接口证实
  401，检查链路从未真正查过。

### 重新登录后，「需重新登录」提示现在会消失

此前该提示只在「再次跑过检查」后才会消失，重登后回到订阅页仍挂着。现在订阅页按**当前**
登录态判定，重登即消；若凭据仍无效（残留过期凭据），下次检查会如实把提示带回来。

### CLI `check-now --accounts` 现在能用 `list` 给的 fakeid 了

`subscription list` 输出归一后的 `MP_WXS_` 形态 fakeid，但 `--accounts` 按字面比对磁盘里的
base64 形态——按 list 给的值传参永远 `accounts:0`。现在按身份归一匹配，两种形态均可。

- 传输层 401 语义、cover 回退两分支、fakeids 归一匹配均有单测钉住。
