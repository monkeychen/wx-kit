## 新增

### 订阅行内：每轮检查的文章清单与状态

- 检查更新后（无论「自动下载」还是「仅提示」），公众号行内展开即显示**本轮检查涉及的文章**
  及各自状态：已下载 / 文库已有 / 下载失败（悬停看原因）/ 不可访问 / 未下载。列表保留到该号
  下一次检查为止，重启应用不丢。
- 「仅提示」策略下，未下载的文章每篇带**「下载」按钮**——单篇下载走全局请求保护（串行/守卫），
  完成后状态就地更新。原有勾选批量下载、「忽略」、「下载全部待处理」全部保留。
- 点**已下载/文库已有**文章的标题 → 直接打开阅读器；点未下载/失败的文章标题 → 在浏览器打开
  原文（保留既有行为）。
- 行内摘要新增「发现 N 篇，待下载」话术（提示策略检查后）。
