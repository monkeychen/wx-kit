# v0.10.1 发布说明

## 订阅可靠性

- `cover` 订阅以稳定 `reviewId` 判重；同一篇文章不会因检查时刻变化反复报新。
- 微信短链 `~`/`_` 兼容形态归一，下载成功后可正确清除待处理项，自动下载完成不再让订阅页永久禁用。
- 微信读书业务请求成功后持久化最新 Chromium Cookie 快照，独立 CLI 进程可复用轮换后的会话；401/403 不覆盖已有凭据。

## 每日订阅日报

- `subscription digest --date <日期>` 默认纯本地，按 `library.json` 中真实 `publishTime` 的北京时间日期查询，不需要登录。
- `subscription digest --date today --download` 仅今天可用：显式刷新所选账号的最新 cover，下载缺失文章，再重读文库返回当天清单。
- 历史日期不能用 `--download` 回补，命令会在联网前以 `DOWNLOAD_TODAY_ONLY` 拒绝。
- 发表时间无法解析时正文仍保存并告警；日报排除该条目，返回 `unknownPublishTimeCount`。

## 已知边界

- 微信读书每个公众号只返回最新一篇；两次刷新之间被覆盖的文章无法自动找回。
- 日报只代表本地已保存内容，不是完整发布历史。

## 验证

- 62 个测试文件、522 项测试通过；lint、TypeScript 检查、macOS arm64/x64 打包通过。
- GUI fixture e2e、打包 CLI 的本地发表日期查询、真实 cover 刷新和跨进程会话复用均已验证。
- macOS 安装包未签名、未公证；安装后仍需执行 `xattr -cr`。
