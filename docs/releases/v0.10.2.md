# v0.10.2 · 订阅自动下载可感知 + 文库直达

发布日期：2026-09-04 · 里程碑 M56 · 需求/验收 `docs/PRD-v0.10.2.md`

## 新增

### 订阅：自动下载结果可感知

- 定时自动检查/自动下载完成后，**下载明细持久落盘**：每条检查记录含「刚下载/文库已有/失败/不可访问」
  汇总与逐号逐篇明细（标题 + 状态），重启应用后仍可查。「文库已有」不并入「刚下载」。
- 订阅页每号行内显示**最近一次结果摘要**（如 `· 自动 · 发现 1 篇，已下载 1 篇`），区分发现与交付及
  触发方式（自动/手动/补下载）。
- 检查记录弹窗可展开**逐篇明细**（标题 + 状态四色标签），旧记录渲染不变。
- 手动「下载全部待处理」同样落记录（`kind:download`），行内摘要为纯交付话术、不冒充「发现」。
- CLI：`subscription list` 输出新增 `recentLog`（最近 5 条记录，agent 查「今天自动下载了什么」的入口）；
  `subscription check-now` 的逐号 `results[]` 含逐篇 `articles` 明细。`agent/wx-kit-skill` 已同批更新。

### 订阅：每号直达文库

- 订阅页每个公众号行内新增常驻「文库」入口，点击进入文库页并**按该号筛选**，一键清除回全部。
- 匹配按公众号稳定身份（`MP_WXS_` 形态，base64 历史形态归一后等价），改名不失联；旧库条目按名称兜底。
- 该号文库为空时显示专属空态（「该公众号还没有已下载的文章」），与全局空文库话术区分。

### 阅读器：外链修复

- 修复 HTML 视图内点「原文」等外链报 `ERR_BLOCKED_BY_RESPONSE` 无法打开的问题：外链现统一用
  **系统默认浏览器**打开。存量已下载文章无需重新下载即生效。

## 补齐

- v0.10.1 验收遗留三条补齐：真实文章 URL 下载、真实 `cover` 增量检查（首检一次、复检不重复）、
  全链路验证行（`docs/PRD-v0.10.1.md` §6 已逐条补勾）。

## 已知边界

- 微信读书每个公众号只返回最新一篇；两次刷新之间被覆盖的文章无法自动找回（服务端列表接口按账号
  封禁，恢复条件只能是官方放开）。
- 日报只代表本地已保存内容，不是完整发布历史。
- macOS 安装包未签名、未公证；安装后仍需执行 `xattr -cr`。
- Windows CLI 的 stdout 仍需重定向到文件（`> out.json`），正解（console 子系统入口）推迟到铺
  Windows agent 场景时做。
