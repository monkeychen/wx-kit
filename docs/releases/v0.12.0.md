# v0.12.0 · 选题工作台——从素材到「今天写什么」

发布日期：2026-09-25 · 功能版本 · 需求/验收 `docs/PRD-v0.12.0.md`

v0.12.0 把 wx-kit 从「本地资料库」推进为**可解释的选题工作台**：选中本地素材，
得到最多三张写明理由、材料依据与起笔结构的候选卡——每条判断可回溯到当轮不可变的
正文快照，程序重算统计，模型失败不伪装成「没有值得写的」。

## 新增

### 选题（GUI + CLI，核心能力）

- **GUI「今天写什么」**：导航新增「选题」页。选完素材点分析，三张候选平等展示、
  默认不替你选；点开看「为什么值得写 / 材料依据 / 怎么下笔」，材料摘录逐字可定位，
  并明确标注「摘录存在不等于事实已验证」。
- **输入素材只有一条路**：点「输入素材」从文库勾选文章（上限 30 篇 / 12 万去重字符）。
  选稿弹层**筛选为主、搜索为辅**——时间快捷段（默认近 30 天）、来源分组下拉、排序、
  标题关键词；已选跨筛选保留；行内「看一眼」看摘要（作者摘要优先，缺失时给正文开头）、
  「查看原文」跳阅读器，返回选稿现场原样恢复。
- **历史选题**：每次分析自动落盘，历史入口可列举（时间倒序，含状态与候选标题）、
  回看（反馈、简报继续可用）、删除——「仅从列表移除」与「删除记录和本地文件」两档分明。
- **反馈与简报**：对候选记录「暂不写 / 保存观察 / 已经写过」；一键生成 Markdown 选题
  简报并复制。
- **CLI 对等**：`wx-kit topics analyze --range 24h|3d|7d|custom [--from/--to] |
  --article <id...>`，`wx-kit topics brief --run <id> --topic <id>`；stdout 纯 JSON，
  供 agent 与脚本消费。CLI 仍保留时间窗口选材（GUI 收敛为人工选篇）。

### AI 模型设置（BYOK，多厂商）

- **7 厂商 + 自定义**：智谱 / 千问 / DeepSeek / Kimi / MiniMax / OpenAI / Google，
  端点按厂商+计费模式自动确定；推理偏好（thinking / reasoning_effort）只对有文档
  依据的厂商下发，五档可选。
- **安全 Key**：Key 用系统加密（Electron safeStorage）落盘；加密不可用时仅本次会话
  内存保存，绝不降级明文。「测试连接」验草稿配置。正文出机边界明示，Key/Authorization
  不进日志与产物。

### 全链路流式

- 所有模型请求走 SSE 流式，分析过程实时可见（正文与思考分段、自动滚动），运行中可
  随时取消；不设总超时，仅保留空闲上限（连续 180s 无字节判死）。端点不支持流时自动
  回退 JSON。

## 修复

### Windows 首个正式版：阅读器图片/封面全挂（ERR_FILE_NOT_FOUND）

Windows 下文库目录分隔符为反斜杠，阅读器取图时路径前缀匹配恒失败，绝对路径被塞进
本地协议 URL 后又被折叠成不存在的嵌套路径。现比较前统一分隔符；协议层同时拒判盘符
形态的路径段，即使上游出错也只是图片不显示（可解释的降级），不会再静默读错文件。

## 升级说明

- macOS（Homebrew）：`brew update && brew upgrade --cask wx-kit && xattr -cr /Applications/wx-kit.app`
- 直接下载：`wx-kit-0.12.0-arm64.dmg`（Apple Silicon）/ `wx-kit-0.12.0.dmg`（Intel）/
  `wx-kit.Setup.0.12.0.exe`（Windows）
- 无数据迁移；新功能零配置起步——在「设置 → AI 模型」选厂商、填 Key 即可开始选题，
  不配置不影响既有下载/阅读/订阅功能。
