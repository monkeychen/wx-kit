# v0.12.1 · 界面收拾干净 + README 下载入口

发布日期：2026-09-29 · 修复与体验版本 · 需求/验收 `docs/PRD-v0.12.1.md`

v0.12.1 是 v0.12.0 选题工作台发版后的第一轮修正，全部来自真实使用反馈：两处界面在
Windows 上不像产品该有的样子，两处页面在窗口变大时不跟着变宽，外加把 README 补成
访客能直接下载的入口页。**无新功能，无数据格式变化，无迁移动作。**

## 修复

### Windows / Linux 不再显示默认菜单栏（M79）

- 主窗口顶部原本挂着 File / Edit / View / Window / Help——项目从未调用
  `Menu.setApplicationMenu()`，Electron 在非 macOS 平台会给每个窗口挂默认应用菜单。
  wx-kit 是纯内容型 UI（刊头已有品牌区、导航与全部动作），这排菜单没有一项是用户需要的。
- 修复一行：GUI 分支 `if (process.platform !== 'darwin') Menu.setApplicationMenu(null)`。
  应用菜单是**进程级全局**，主窗口与扫码登录窗口一并生效。macOS 行为零变化。
- 随菜单移除的 Ctrl+R / F12 等加速器本就不该在生产环境暴露；应用内复制走主进程
  `clipboard:write` IPC、选中文本 Ctrl+C 是 Chromium 内建行为，均不依赖菜单（已逐项核实）。

### 设置页与选题页随窗口变宽（M80）

- 现象：拖大主窗口时设置页与选题页内容**不跟着变宽**，左右留白持续扩大；缩小时却正常。
- 根因是两处写死的容器宽度——设置页 `.settings-shell` 的 `max-width: 1420px`
  （v0.12.0 复原设计稿时按原型画布尺寸带进）、选题页 `.topic-page-inner` 的 `1240px`。
  M80 原型的 1420px 是**设计稿画布尺寸，不是用户约束**。
- 修复=两处去掉 `max-width`，与文库页等页面保持一致的全宽自适应风格；选题候选卡保持
  3 列铺满（产品上限就是 3 张卡，变宽只意味着单卡更宽）。缩小方向的 900px / 980px
  断点降级未改动。

## 文档

- **README 补下载入口**：新增「下载」段——各版本安装包累计下载数趋势图（手绘风 SVG，
  随 GitHub 深浅色主题切换）、总下载与分平台实时徽章（shields.io，数字自动跟随）、
  三平台安装包直链（含文件大小），访客进仓库即可取包，不必先找 Releases 页。
- 说明中明确标注口径：图中数字是**每个版本自发布至今的累计下载数**，不是按天增量
  （GitHub 不提供下载量时间序列 API）；统计已排除 `.blockmap`（差分更新元数据）。
- 维护方式：`npm run docs:download-stats` 重新生成（幂等，带 `--check` 漂移检测），
  已并入发版规约。
